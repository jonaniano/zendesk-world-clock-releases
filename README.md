# Zendesk World Clock - Releases

This repository hosts the releases and update feed for Zendesk World Clock, a macOS menu bar app for tracking time across global offices.

## Download

**[Download Latest Version](https://github.com/jonaniano/zendesk-world-clock-releases/releases/latest)**

## System Requirements

- macOS 14.0 (Sonoma) or later
- Apple Silicon or Intel Mac

## Features

- Real-time clock updates for 22+ cities
- Working hours indicators (green/yellow/red status)
- Smart notifications when cities come online
- Custom cities with any timezone
- Time Input Mode for meeting planning
- 19 language support
- Auto-updates via Sparkle

## Installation

1. Download the latest DMG from [Releases](https://github.com/jonaniano/zendesk-world-clock-releases/releases)
2. Open the DMG and drag the app to Applications
3. Launch from Applications or Spotlight

The app will automatically check for updates daily.

## Update Feed

The app uses Sparkle for automatic updates. The update feed is located at:
